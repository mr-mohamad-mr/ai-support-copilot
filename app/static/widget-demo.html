Embeddable chat widget

One script tag adds a floating support chat to any website. It talks to the same /chat endpoint as the app, shows citations, and flags handoffs to a human.

Embed snippet

<script src="/static/js/widget.js"
        data-api=""
        data-token="PASTE_A_SUPPORT_TOKEN_HERE"
        data-title="Need help?"></script>

Use a dedicated support user for the widget token and rotate it like any credential. data-api is the Copilot base URL (empty means “same origin as this page”). The button at the bottom right of this page is the live widget — it needs a token to answer. Get one by signing in to the app and using its login token, or leave the demo as-is to see the unconfigured state.
