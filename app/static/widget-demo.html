Embeddable chat widget

One script tag adds a floating support chat to any website. It talks to the same /chat endpoint as the app, shows citations, and flags handoffs to a human.

Embed snippet

<script src="https://YOUR-COPILOT-HOST/static/js/widget.js"
        data-api="https://YOUR-COPILOT-HOST"
        data-widget-key="wk_YOUR_PUBLIC_WIDGET_KEY"
        data-title="Need help?"></script>

Setting it up

  1. Sign in as the workspace owner or an admin, open Admin → Website widget and create a widget key (or call POST /widget-key). The key is shown once; rotating it disables the old one immediately.
  2. Add your website's origin, e.g. https://shop.example.com, to the allowed origins. Browsers on any other site are refused.
  3. Paste the snippet with your key. data-api is the Copilot base URL (empty means “same origin as this page”).

The widget key is public by design: it can only ask questions through /chat, is rate limited per visitor, and cannot read or change documents, users or conversations. Never put a login token in a web page.

The button at the bottom right of this page is the live widget, shown unconfigured. Pages served by the Copilot itself are always an allowed origin, so you can try a key here by adding data-widget-key to this page's script tag.
